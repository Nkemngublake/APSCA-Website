# APSCA Website

## Overview
APSCA (Action pour la Promotion de la Santé au Cameroun) is a static website for a Cameroonian NGO focused on public health promotion. The site is built with Vite and vanilla JavaScript.

## Project Structure
- `index.html` - Main HTML entry point
- `src/` - JavaScript and CSS source files
  - `main.js` - Main JavaScript logic
  - `style.css` - Main stylesheet
  - `projects.css` - Projects section styles
  - `recruitment.css` - Recruitment section styles
- `public/` - Static assets (images, logos)
- `vite.config.js` - Vite configuration

## Technology Stack
- Vite 7.x (build tool and dev server)
- Vanilla JavaScript (ES modules)
- CSS3

## Development
- Run `npm run dev` to start the development server on port 5000
- Run `npm run build` to build for production (outputs to `dist/`)

## Deployment
Configured for static deployment. The build outputs to the `dist` directory.
